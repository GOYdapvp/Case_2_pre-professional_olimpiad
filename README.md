Командный кейс №2: "SmartFridge: QR Control & IoT Sync"

Это мобильное приложение, которое помогает владельцам кафе решать проблему неэффективной инвентаризации и закупок продуктов при помощи автоматизированного отслеживания содержимого холодильника через сканирование QR-кодов на продуктах. Приложение дает возможность оптимизировать закупку продуктов, экономить время на инвентаризации продуктовых запасов в холодильнике и отслеживать актуальное содержимое.

## Установка:
открыть releases -> скачать apk файл, запустить его (и всё)
