# Это кейс 2: "SmartFridge: QR Control & IoT Sync"

Данный проект представляет собой приложение (и датабазу) по контролю продуктов в холодильнике пользователя с помощью qr кодов (а именно их срок годности и их наличие)

## Установка:
открыть frontend -> link.txt -> скопировать ссылку и перейти на диск -> скачать apk файл, запустить его (и всё)
