Командный кейс №2: "SmartFridge: QR Control & IoT Sync"

Это мобильное приложение, которое помогает владельцам кафе решать проблему неэффективной инвентаризации и закупок продуктов при помощи автоматизированного отслеживания содержимого холодильника через сканирование QR-кодов на упаковках продуктов. Приложение дает возможность оптимизировать закупку продуктов, экономить время на инвентаризации продуктовых запасов в холодильнике и отслеживать актуальное содержимое в нём.

# Установка:
открыть releases -> скачать apk файл и установить на телефон с ОС Android.

# Примечания:
1 - На данный момент приложение работает в моно-пользовательском режиме, это позволяет осуществлять возможность его использования даже без подключения к сети Интернет, ввиду использования локальной БД на основе SQLite. Дальнейшие версии продукта будут доработаны: добавится возможность синхронизации результатов сканирования и хранения данных о продуктах в холодильнике в много-пользовательском режиме путём синхронизации данных локальной БД на устройстве с централизованной БД на сервере сети Интернет. Централизованная БД реализована путём разработки REST full-API на языке программирования Python, СУБД PostgreSQL, установленных на сервере с ОС Centos 9. Сервер предоставлен облачным провайдером MakeCloud.ru.
